# تطبيق المصحف الصوتي الميسر (Accessibility-First Quran PWA)

تطبيق ويب تقدمي (PWA) فائق السرعة، مصمم ومبني خصيصاً لخدمة **فاقدي البصر، كبار السن، وذوي الاحتياجات الخاصة**، لتمكينهم من تلاوة وتدبر القرآن الكريم بالكامل دون الحاجة للنظر إلى الشاشة، بالاعتماد على **الأوامر الصوتية الذكية باللغة العربية** و**الإيماءات اللمسية الشاملة** والاهتزازات الحسية (Haptic Feedback).

---

## 🌟 أبرز مميزات التطبيق

### 1. تجربة خالية من الشاشات (Eyes-Free UX)
* **الميكروفون الذكي:** نقرة مطولة في أي مكان على الشاشة لفتح الميكروفون والتحدث مباشرة.
* **التحكم باللمس:** 
  * **نقرتان (Double Tap):** تشغيل أو إيقاف مؤقت للتلاوة.
  * **سحب أفقي (Swipe Left / Right):** الانتقال الفوري للآية التالية أو السابقة.
  * **سحب لأسفل:** تكرار الآية الحالية 3 مرات (للحفظ والمراجعة).
  * **سحب لأعلى:** نطق اسم السورة ورقم الآية الحالية صوتياً للمكفوفين.
* **ردود فعل حسية (Haptics):** اهتزازات مميزة بكل إجراء (بدء الاستماع، نجاح الأمر، الخطأ، الانتقال بين الآيات).
* **إشارات صوتية (Earcons):** نغمات صوتية مركبة عبر Web Audio API بدون أي ملفات خارجية.

### 2. محرك فهم الأوامر الصوتية العربي (Voice Engine)
يفهم الأوامر المنطوقة باللهجات المختلفة والفصحى:
* *"سورة الكهف بصوت الحصري"*
* *"شغل سورة البقرة من الآية 255"*
* *"اقرأ آية الكرسي"*
* *"كرر الآية ثلاث مرات"*
* *"وقف القراءة"* / *"استمر"*
* *"ما معنى هذه الآية"* (جلب التفسير الميسر ونطقه صوتياً)

### 3. دعم كبار القراء بتلاوة متصلة آية تلو آية (Gapless Audio)
* الشيخ محمود خليل الحصري
* الشيخ محمد صديق المنشاوي
* الشيخ عبد الباسط عبد الصمد
* الشيخ مشاري بن راشد العفاسي
* الشيخ ماهر المعيقلي
* الشيخ علي عبد الرحمن الحذيفي
* الشيخ سعد الغامدي
* الشيخ أحمد بن علي العجمي
* *ميزة Preloading:* تحميل مسبق للآية التالية في الخلفية لضمان تلاوة مستمرة دون أي توقف أو تقطيع.

## 📊 لوحة تحكم وإحصائيات الأدمن (`/admin.html`)

لوحة تحكم خاصة ومحمية برمز مرور (الافتراضي: `2026`):

1. **المؤشرات الحيوية المباشرة (Live KPI Cards):**
   * إجمالي عدد المستخدمين المتصلين.
   * إجمالي الآيات التي تم الاستماع إليها تراكمياً.
   * نسبة دقة التعرف الصوتي (Voice Accuracy Rate).
   * القارئ الأكثر شعبية واستماعاً.
2. **سجل الأوامر الصوتية الحي (Voice Telemetry Audit Log):**
   * عرض كل عبارة ينطق بها أي مستخدم حرفياً مع وقتها.
   * تصنيف النية المستخرجة وحالة النجاح والفشل لمساعدتك في تدريب النظام على مختلف اللهجات.
   * إمكانية تصدير السجلات بصيغة JSON.
3. **دليل وسلوك المستخدمين (Users Directory):**
   * معرف كل مستخدم (UID)، نوع جهازه، هل ثبت التطبيق كـ PWA، وآخر موضع توقف عنده.
4. **نظام البث والتنبيهات المباشرة (Live Broadcast):**
   * إرسال تنبيه أو رسالة صوتية ترحيبية تظهر أو يقرؤها التطبيق لجميع المستخدمين فوراً.

## 🔒 قواعد أمان Firestore (Firebase Rules)

انسخ هذه القواعد وضعها في تبويب **Rules** في مشروع Firebase كما في لوحة التحكم الخاصة بك:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // سجلات المستخدمين
    match /users/{userId} {
      allow read, write: if true;
    }
    
    // سجلات الأوامر الصوتية لتحليلات الأدمن
    match /voice_logs/{logId} {
      allow read, write: if true;
    }
    
    // تنبيهات البث وإعدادات النظام
    match /system_config/{configId} {
      allow read: if true;
      allow write: if true;
    }
    
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

## 🚀 النشر على Vercel و GitHub

المشروع مصمم كـ Static PWA بدون أي سيرفر ثقيل، وجاهز للرفع بنقرة واحدة:
1. ارفع المجلد إلى مستودع GitHub.
2. افتح [Vercel](https://vercel.com) واختر **Import Project** من المستودع.
3. اضغط **Deploy** وستحصل على رابط HTTPS حي وتطبيق PWA قابل للتثبيت على أي هاتف فوراً!
